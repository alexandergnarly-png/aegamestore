# Design System: AE Game Store — KEY//SYSTEM
**Project ID:** Local repository · WEBTOKOGAME

## 1. Visual Theme & Atmosphere
Nothing-inspired industrial minimalism meets a compact bento control surface. The interface feels precise, quiet, and operational: monochrome surfaces, exposed grid lines, terse system labels, and generous negative space. Gaming identity comes from the command-center composition rather than neon decoration.

## 2. Color Palette & Roles

- **Chalk Canvas (#ECECE4):** Primary light-page background with a warm hardware-like character.
- **Paper Module (#F7F7F1):** Main cards, login surfaces, and elevated light containers.
- **Pressed Module (#DEDED7):** Secondary controls, inactive states, and subtle grouping.
- **System Black (#0B0B0A):** Primary text, dark feature panels, and decisive actions.
- **Night Canvas (#080808):** Primary dark-page background.
- **Night Module (#101010):** Dark cards and form surfaces.
- **Graphite Module (#181818):** Dark secondary controls and input backgrounds.
- **Utility Grey (#666661 / #A2A29C):** Supporting copy and metadata in light / dark mode.
- **Hardware Line (#C6C6BE / #2A2A27):** Dividers, card boundaries, and form strokes in light / dark mode.
- **Signal Red (#A32626):** Validation and destructive/error feedback only.

## 3. Typography Rules

Space Grotesk carries headlines, interface copy, and large statements with tight negative tracking. DM Mono carries module numbers, status labels, field labels, and primary button copy. Headings are bold and compact; body copy stays medium-weight with relaxed line height. Uppercase is reserved for short system metadata, never paragraphs.

## 4. Component Stylings

* **Buttons:** Near-square corners (2–3px), high-contrast solid primary actions, 44px minimum touch targets, and one-pixel borders. Hover movement is limited to one or two pixels.
* **Cards/Containers:** Modular bento blocks with sharp 3px corners, one-pixel hardware lines, flat depth, and no decorative drop shadows.
* **Inputs/Forms:** Pressed module backgrounds, persistent labels, 56px minimum height, direct error copy, and a high-contrast focus ring visible in both themes.

## 5. Layout Principles

Use a disciplined grid with 8px internal bento gaps and 48px ambient background lines. Desktop login uses a split composition: narrative control panel on the left and task-focused form on the right. The left side collapses completely below tablet width so the login task remains fast and uncluttered. Decorative marks stay behind content and never carry meaning.
